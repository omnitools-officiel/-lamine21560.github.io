# ToolBox Pro — version préparée pour la monétisation

## À faire avant publication
1. Remplacer `TON-NOM.github.io` par l'URL GitHub Pages réelle dans `index.html`, `robots.txt` et `sitemap.xml`.
2. Remplacer `contact@exemple.com`.
3. Vérifier et adapter les pages Confidentialité et Conditions selon les services réellement utilisés.
4. Tester chaque outil, chaque lien et le site sur téléphone.
5. Ajouter du contenu original et utile régulièrement.
6. Ne pas placer de vrai code publicitaire avant d'avoir un compte/réseau publicitaire approprié.
7. Quand AdSense est approuvé, utiliser exactement le code fourni par Google et ajouter les informations de cookies/consentement nécessaires.

## Important
Les blocs PUBLICITÉ sont des emplacements visuels. Ils ne génèrent aucun revenu.
`ads.txt` ne doit être publié qu'avec la ligne fournie par le réseau publicitaire.


## Version iPhone
Tous les fichiers du site sont volontairement à la racine de ce dossier pour faciliter la sélection multiple dans l’application Fichiers sur iPhone. Il faut envoyer tout le contenu de ce dossier dans le dépôt `lamine21560.github.io`, pas le dossier lui-même et pas le ZIP.
